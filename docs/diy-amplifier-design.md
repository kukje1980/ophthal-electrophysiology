# 자체 ERG/VEP 앰프 개발 가이드 (2026-11)

> 질문: "앰프를 직접 만든다면 어떻게 해야 하는가."
> 전제: 노이즈에 강해야 하고, 본 프로그램(`ophthal-electrophysiology`)에 바로 연결돼야 한다.
> 사양 수치는 TI ADS1299 데이터시트(SBAS499C)와 표준 요약 검색 결과 기준이다. ti.com·iscev.org·식약처 사이트는 이 세션에서 직접 열리지 않았다.
> **(추정)** 표시는 검증하지 않은 설계 판단이나 예산이다.

## 1. 결론 요약

| 항목 | 권장 |

| 핵심 부품 | **TI ADS1299** (8채널 동시 샘플링, 24-bit, PGA, DRL 앰프·전극 탈락 검출·테스트 신호 내장) |

| PC 연결 | USB 가상 COM(CDC) + 바이너리 샘플 프레임. 본 프로그램에는 `SampleStream` 드라이버 1개(약 150–200줄)로 붙는다 |

| 먼저 할 일 | **통신 프로토콜을 먼저 확정**한다. 그러면 펌웨어와 호스트 드라이버(+장치 에뮬레이터)를 동시에 개발할 수 있다(§5) |

## 2. 목표 사양

| 항목 | 목표 | 근거·메모 |
|---|---|---|
| 채널 | **차동 4채널**: OD, OS, VEP(Oz–Fz), 예비(EOG·포토다이오드) | ffERG/PERG는 양안 동시, VEP는 1–3채널. ADS1299-4로 충분하고, 8채널(ADS1299)이면 확장 여유가 있다 |
| 입력 잡음 | ≤ 0.5 µV rms (0.3–300 Hz, 입력 단락) | ADS1299 게인 24: 1 µVpp(0.01–70 Hz), 1 kSPS에서 1.97 µVpp(262 Hz 대역) |
| 샘플링 | **2 kSPS** (옵션 4 kSPS) | ADS1299 −3 dB 대역 ≈ 0.262 × 데이터율 → 1 kSPS는 262 Hz라 OP(75–300 Hz)에 부족. 2 kSPS(≈ 524 Hz)로 받고 소프트웨어에서 0.3–300 Hz로 거른다 |
| 결합·게인 | DC 결합, PGA ×24 고정 | 입력 범위 약 ±187 mV(4.5 V 기준전압). 전극 오프셋·깜빡임에도 포화되지 않아 게인 전환이 필요 없다 |
| 분해능 | 24-bit, LSB = 4.5 V / (24 × 2²³) ≈ **22.35 nV** | 호스트 µV 환산 계수 |
| CMRR | ≥ 110 dB (DRL 포함 실측 ≥ 100 dB) | ADS1299 CMRR −110 dB |
| 입력 임피던스 | ≥ 500 MΩ | ADS1299 1000 MΩ(전극 탈락 검출 끔), 500 MΩ(6 nA 전류원 검출 켬) |
| 전극 임피던스 측정 | 약 30 Hz 교류로 kΩ 표시, < 5 kΩ 경고 | ADS1299 AC 전극 탈락 검출 7.8 / 31.2 Hz. 본 앱 Live 화면의 임피던스 모니터와 연동 |
| 트리거 | 지터 ≤ 1 샘플(2 kSPS에서 0.5 ms), 고정 지연 보정 | MCU 타이머 입력 캡처(§4.9) |
| 환자 안전 | BF 등급, 환자-PC 사이 **2 MOPP** | 각막(DTL) 전극이 직접 닿는 장착부. IEC 60601-1 |

## 3. 블록 구성

```text

                                                                    │      │
 전극 ─ 보호·RF 필터 ─ ADS1299 ── SPI ── MCU(STM32 등) ── USB 절연기 ─┼──────┼─ USB ─ PC(본 프로그램)
 OD+/OD−                (8ch 24-bit,       │                         │      │
 OS+/OS−                 PGA×24,           └─ 타이머 캡처 ◄─ 광절연 ◄─┼──────┼─ 자극기 TTL
 Oz/Fz                   BIAS=DRL)                                   │      │
 GND(이마) ◄─ 전류제한 ─ BIAS 출력                                   │      │
                 ▲                                                  │      │
```

자극기는 상용 전원 접지에 붙어 있다. 그래서 트리거 선도 반드시 광절연(또는 디지털 절연기)을 거쳐 환자측으로 들어와야 한다.

## 4. 설계 세부(노이즈 중심)

### 4.1 AFE 선택: ADS1299
- 8채널 동시 샘플링 24-bit ΔΣ ADC + PGA(×1–24)에 BIAS(DRL) 앰프, 전극 탈락 검출, 내부 테스트 신호가 한 칩에 들어 있다. 4·6채널 변형(ADS1299-4/-6)이 있다.
- 오픈소스 EEG(OpenBCI 등)와 다수 연구용 장비에서 검증된 부품이라 참고 회로가 많다.
- 대안 비교:
  - 개별 계측앰프 + ADC: 부품 수와 검증 부담이 크다.
  - 신경 스파이크용 칩(Intan 등): µV 단위 잡음이 커서 PERG(2–8 µV)에는 불리하다 **(추정)**.

### 4.2 몽타주와 입력
- 채널마다 진짜 차동 입력으로 쓴다.
  - CH1: OD 활성(+) / OD 기준, 외안각(−)
  - CH2: OS 활성(+) / OS 기준(−)
  - CH3: Oz(+) / Fz(−)
  - CH4: EOG 또는 섬광 포토다이오드
- 이마 접지 전극은 ADS1299 **BIAS 출력(DRL)**에 연결한다. 공통모드를 능동적으로 눌러 60 Hz 험을 크게 줄인다.
- 커넥터는 **1.5 mm 터치프루프(DIN 42802)**로 한다. DTL, 피부 전극, 컵 전극을 모두 그대로 꽂을 수 있다.

### 4.3 보호·RF 필터
- 입력마다 직렬 저항 + 저누설 TVS + RC 필터를 넣는다.
- 직렬 저항은 열잡음과 맞바꾼다. 5 kΩ이면 약 9 nV/√Hz이고, 300 Hz 대역에서 약 0.16 µV rms다. 수 kΩ 수준으로 둔다.
- **+/− 입력 쌍의 부품값을 0.1 % 수준으로 맞추고 배선을 대칭으로** 한다. 불평형이 있으면 공통모드 험이 차동 신호로 바뀐다. CMRR을 좌우하는 가장 큰 요인이다.

### 4.4 DRL(BIAS) 안전
- BIAS 출력에 직렬 저항을 둬서, 정상 상태와 단일 고장 상태 모두에서 **환자 보조전류 한계** 안에 들도록 제한한다. IEC 60601-1 기준으로 정상 상태 DC 10 µA 수준이며, 규격 표로 확인한다.
- 전극 탈락 검출 전류는 nA 단위(예: 6 nA)로 설정한다.

### 4.5 전원
- **최선은 배터리(리튬이온) + 저잡음 LDO**다. 스위칭 잡음이 없고, 상용 전원과 완전히 분리된다.
- 충전 중에는 측정을 막는 인터록을 둔다. 또는 충전 회로까지 2 MOPP로 절연한다.
- 절연 DC-DC를 쓸 경우: 의료용 2 MOPP 부품 → LC 필터 → LDO 순으로 구성하고, 스위칭 주파수를 측정 대역과 데이터율의 배수에서 멀리 둔다.
- 아날로그 전원은 ±2.5 V 양전원으로 한다. DC 결합 입력이 0 V 중심이 되도록 하기 위해서다.

### 4.6 절연
- MCU까지 환자측에 두고 **USB 데이터선을 절연**한다. 예: ADuM4160(5 kV USB 절연기, 의료 용도 표기, 연면거리 강화 패키지 있음).
- 다만 2 MOPP(시험전압 4,000 VAC, 연면거리 8 mm 수준) 충족 여부는 **해당 패키지의 인증 데이터로 확인**해야 한다.
- 다른 방법: SPI 선을 의료용 디지털 절연기로 끊고 MCU를 PC측에 둘 수도 있다. 이 경우 절연 경계를 넘는 신호 선이 많아진다.

### 4.7 PCB·차폐
- 4층 기판, 끊김 없는 접지면. ADS1299를 커넥터 바로 옆에 두고, 아날로그 영역과 디지털·USB 영역을 분리한다.
- 금속(또는 도전 코팅) 외함을 환자측 기준에 연결한다.
- 전극선은 차폐선을 쓰고, 필요하면 공통모드 전압을 버퍼로 차폐선에 구동한다(능동 차폐). 케이블 움직임 잡음과 험이 줄어든다.

### 4.8 샘플링·필터 분담
- 장치는 2 kSPS 원신호만 보낸다(장치 쪽 하드웨어 필터 최소).
- 0.3 Hz 하이패스, 300 Hz 로우패스, 필요할 때의 60 Hz 노치는 **소프트웨어**에서 처리한다. 본 앱 `app/acquisition/filters.py`에 이미 상태 유지형 노치와 DC 차단 필터가 있다.
- 장점: 검사 단계별 필터 설정을 소프트웨어가 정하고, 원신호가 남아 다시 분석할 수 있다.

### 4.9 트리거
- 경로: 자극기 TTL → 고속 광절연 → MCU **타이머 입력 캡처**. MCU가 그 에지가 속한 **샘플 번호와 샘플 내 위치**를 프레임에 기록한다.
- 데이터와 트리거가 같은 클럭이므로 USB 지연·지터가 결과에 영향을 주지 않는다.
- 섬광 지연(전기 트리거 → 실제 빛)은 포토다이오드로 한 번 측정해 보정값으로 저장한다. 또는 CH4에 포토다이오드를 상시 기록한다.
- ADS1299 GPIO를 상태 워드로 읽는 방법도 있다. 다만 짧은 펄스를 놓칠 수 있어 타이머 캡처를 권장한다(상태 워드 형식은 데이터시트 확인).

### 4.10 임피던스 측정
- 기록 전 **임피던스 모드**: ADS1299 AC 전극 탈락 검출(31.2 Hz, nA 전류)로 전극별 진폭을 재고 kΩ로 환산한다.
- 교류 여기 신호가 기록 신호에 섞이므로, 측정 중에는 기록하지 않는다.
- 기록 중 상시 감시가 필요하면 대역 밖 주파수로 여기하고 소프트웨어 LPF로 제거하는 방식을 검토한다(경향 표시용, **추정**).

### 4.11 자체 교정
- ADS1299 내부 테스트 신호(사각파)를 켜면 본 앱 Live 화면의 **CAL 측정 → 게인 보정**을 그대로 쓸 수 있다. 진폭은 데이터시트 CONFIG2 식으로 계산한다.
- 출하 검사에서는 외부 정밀 신호발생기로 확인한다.

## 5. 프로그램 연동: 통신 프로토콜(제안)

**전송 방식**: USB CDC(가상 COM). 호스트는 `pyserial`로 읽는다.

**명령**(PC → 장치, ASCII 한 줄)

| 명령 | 응답·동작 |
|---|---|
| `ID?` | `KJ-EP1,fw=1.0,ch=4,fs=2000,lsb_nv=22.35` |
| `RATE 2000` | 데이터율 설정(1000/2000/4000) |
| `MODE REC` / `MODE IMP` / `MODE CAL` | 기록 / 임피던스 측정 / 내부 테스트 신호 |
| `START` / `STOP` | 스트리밍 시작·정지 |

**데이터 프레임**(장치 → PC, 한 샘플당 한 프레임, little-endian)

| 필드 | 바이트 | 내용 |
|---|---|---|
| sync | 2 | `0xA5 0x5A` |
| seq | 2 | 샘플 카운터(mod 65536). 끊김 검출용 |
| flags | 1 | bit0 이 샘플에서 트리거 에지, bit1 트리거 레벨, bit2 전극 탈락, bit3 버퍼 넘침, bit4 CAL 모드 |
| trig_frac | 1 | 에지의 샘플 내 위치(0–255 → 0–1 샘플) |
| data | 3 × 채널 수 | ADS1299 원시 코드(int24) |
| crc | 2 | CRC-16/CCITT |

- 4채널이면 프레임당 20바이트, 2 kSPS에서 40 kB/s다. USB Full-Speed로 충분하다.
- 임피던스 프레임: sync `0xA5 0x5B` + 전극별 kΩ × 100(u16) + CRC.

**호스트 드라이버**(`app/acquisition/hw_streams.py`에 추가)
- `register_stream("kj-amp", KjAmpStream)`, 연결 문자열 예: `COM5@2000;eyes=OD,OS,VEP;hp=0.3`.
- `read()`: 프레임을 파싱해 µV로 바꾼다(code × 0.02235). 결과는 `(signals, n)` 배열로 반환한다.
  - flags bit0인 샘플 위치를 `last_triggers`에 넣는다. Live 화면이 그대로 에포크·평균·저장한다.
  - seq가 끊기면 로그를 남기고 빈 구간을 표시한다.
- `impedances()`: 마지막 임피던스 프레임 값을 반환한다. Live 화면의 ISCEV < 5 kΩ 경고가 그대로 동작한다.
- **장치 에뮬레이터**(가상 시리얼 포트로 같은 프레임 생성)를 함께 만든다. 하드웨어 없이 드라이버와 화면을 시험하고, 펌웨어 팀의 기준 구현으로도 쓴다.

## 6. 개발 단계 (기간은 추정)

| 단계 | 내용 | 기간 |
|---|---|---|
| 0. 사양·위험분석 | 요구사양서, ISO 14971 위험분석 착수, 식약처 품목·등급 확인(`망막전위계` 등 품목명은 의료기기 정보포털에서 조회) | 2–4주 |
| 1. 평가보드 시제품 | ADS1299 평가키트(ADS1299EEGFE-PDK) 또는 ADS1299 보드 + STM32. 펌웨어, 프로토콜, 호스트 드라이버 구현. **신호발생기·팬텀으로 벤치 시험만** 한다(절연이 없으므로 사람 측정 금지) | 1–2개월 |
| 2. 자체 PCB v1 | 절연, DRL, 입력 보호, 전원, 외함, 터치프루프 커넥터 | 2–3개월 |
| 3. 검증 | §7 시험. 누설전류·내전압 사전시험 후 IRB 승인을 받아 자원자에게서 **Grass와 동시 기록 비교** | 1–2개월 |
| 4. 인증 | IEC 60601-1(안전), 60601-1-2(EMC), **60601-2-40**(근전도·유발반응 장비 개별 규격, 2024년 3판에서 시각 자극기 요구사항 명확화), IEC 62304(소프트웨어), IEC 62366-1(사용적합성), 식약처 기술문서 심사 + GMP | 6–12개월 이상 |

> **중요:** 앰프를 의료기기로 판매하면 이 프로그램도 기기의 일부가 된다. 따라서 IEC 62304에 맞춘 소프트웨어 개발 문서(요구사항, 설계, 시험, 변경관리)가 필요하다. 지금부터 테스트와 커밋 이력을 그 형식에 맞춰 두면 나중에 부담이 줄어든다.

## 7. 검증 시험 항목(합격 기준은 제안)

| 항목 | 방법 | 목표 |
|---|---|---|
| 입력 잡음 | 입력 단락, 0.3–300 Hz, 60 s | ≤ 0.5 µV rms |
| CMRR | 60 Hz 공통모드 인가, 한쪽 입력에 불평형 임피던스(IEC 60601-2-26식 51 kΩ ∥ 47 nF) | ≥ 100 dB |
| 주파수 응답 | 사인 스윕 0.1–1000 Hz | 0.3–300 Hz 구간 평탄, −3 dB점 기록 |
| 이득 정확도 | 정밀 신호발생기 + 분압기(예: 100 µV) | ±1 % |
| 채널 간 누화 | 한 채널에 큰 신호, 나머지 측정 | ≤ −60 dB |
| 트리거 지연·지터 | 포토다이오드 + 섬광 | 지터 ≤ 1 샘플, 고정 지연 보정 |
| 임피던스 정확도 | 1·5·10·20 kΩ 저항 | ±10 % |
| 큰 신호 후 회복 | 10 mV 펄스 인가 | 즉시(DC 결합이라 포화 없음) |
| 누설전류·내전압 | IEC 60601-1 사전시험 | 규격 이내 |
| 실측 비교 | 자원자, Grass와 같은 전극에서 동시 기록 | 잠복시 차 ≤ 1 ms, 진폭 차 ≤ 5 % **(제안)** |

## 8. 비용(추정)
- 부품: ADS1299는 개당 수만 원대다. MCU, 절연기, 전원, 커넥터, PCB, 외함을 포함하면 시제품 1대당 수십만 원대로 본다 **(추정)**.
- 실제로 큰 비용은 **인증 시험과 문서 작업**이다. KTL·KTC 같은 시험기관 견적을 받아야 한다.

## 9. 주의사항
- 절연 없는 평가보드나 충전 중인 노트북에 연결한 상태로는 **사람을 측정하지 않는다.**
- 각막(DTL) 전극이 닿는 장착부이므로 BF 등급 이상으로 설계한다.
- 자극 반복률을 60 Hz의 정확한 약수에 맞추지 않는다. 험이 자극과 위상 고정되면 평균을 내도 줄지 않는다. ISCEV 허용 범위 안에서 살짝 어긋나게 설정한다.
- 무선(BLE)은 접지 루프가 없지만 처리량과 지연이 불리하다. 트리거를 장치 안에서 기록하면 지연은 문제가 되지 않으므로, 2단계 이후 옵션으로 검토한다.
